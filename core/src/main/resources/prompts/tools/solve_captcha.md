Solve a picture verification (captcha) on the current screen with the captcha service the user set up. It only reads the screen and returns the answer; you then type, tap or drag with the screen tools yourself. Use it after handle_obstacle says captcha, for: text (letters, digits or a sum in a picture), click (tap things in the picture in the order the instruction says), rotate (turn a picture upright), slider (drag a piece into a gap) or question (a text-only question). Give left/top/right/bottom tightly around the whole puzzle picture, not the whole screen; for click copy the on-screen instruction into instruction. Each successful solve costs the user a little money, so call it once per puzzle and look at the screen again before retrying. Not for checkboxes (我不是机器人), sign-in, SMS codes or payment: hand those to the user.
