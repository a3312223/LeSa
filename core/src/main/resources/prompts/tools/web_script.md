Run a JavaScript program against the current web page to do repetitive multi-step work in one call: read many list items, page through results, fill several fields. Not for a single action: use web_tap/web_type_text for that. code is the body of an async function; return a JSON-serialisable value. The script has no DOM: document, window, location, fetch and every other browser global are undefined; only plain JavaScript (Math, JSON, Array, …) and `lesa` are there, and everything lesa returns is plain data (always await): lesa.snapshot() → {snapshotId, elements:[{ref, role, name, center}]}; lesa.read({maxChars, offset}) → page text chunk {text, nextOffset}; lesa.queryAll(cssSelector, {fields: ['text','attrs','value','box'], limit, maxChars}) → {items:[{tag, text, attrs, value, box}], total}; lesa.query(cssSelector, opts) → first item or null (fields ['count'] → number); lesa.text(cssSelector) → visible text (password-like values read as ***); lesa.tap(ref); lesa.type(ref, text, {enter}); lesa.scroll('down'|'up'|'left'|'right', {amount}); lesa.navigate(url); lesa.wait(ms) or lesa.wait({text, timeoutMs}) → true/false; lesa.log(...). tap/type use refs from the latest lesa.snapshot() in the script. Every action runs through the same execution and recording path as a normal call, including send, post, order, delete and pay. A failed lesa call throws an Error whose message starts with the error code. Limits: {{max_actions}} actions, {{max_reads}} reads, {{max_seconds}} s. A navigation that loads a new page ends the script (endedBy=navigation). Returns result (JSON), logs, and actions with each outcome. Call web_observe before acting after it: the page may have changed.
